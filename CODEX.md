objective: create a correction tool for basketball possessions

input will be match video and a json generated by vision pipeline
correction to be done for partial possessions, missing possessions, extended possessions etc
should run on a normal laptop with 8 GB ram
rapid development is necessary, tool will evolve and at some point may merge into existing full pipeline correction tool

functional requirements:
- load and save possession mapping jsons
- save previous 5 copies of mapping json on update
- create, delete, split, join, stretch and shrink possessions
- traverse frame wise, second wise and jump between possessions

non functional requirements:
- smooth video loading and traversel even on 8 GB machine
- show possession on timeline
- allow zoomed in timeline
- optional: start and end mark. since multiple operators will work on same video, this will allow easy boundaries
- show current status on visible area
