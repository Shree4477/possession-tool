🏀 Possession QC Tool — Guide & Shortcuts

Overview

This web application is a frame-accurate quality control tool for basketball match possessions. Everything runs 100% locally in your browser with zero server uploads.

How to Use

  1. Click Open → Open video file (or drop your match MP4/WebM video).
  2. Click Open → Open JSON mapping to load vision pipeline possessions.
  3. Or simply click Open → Load sample demo to try it out immediately!

Timeline Controls

  • Mouse Wheel over detail timeline: zooms in and out centered at pointer.
  • Double Click on timeline: fits view to context.
  • Click on possession or timeline: jumps directly to that frame.
  • Dragging the current-frame playhead line scrubs smoothly through video.

Editing Rules

  • Create (N): Navigate to start frame, press N, navigate to end frame, press N again.
  • Split (S): Position inside an active possession and press S to split before the current frame.
  • Join (J): Merge active possession with the following possession.
  • Stretch Boundaries ([, ]): Adjust start or end frame to current position.
  • Delete (Del): Remove active possession and auto-renumber.
